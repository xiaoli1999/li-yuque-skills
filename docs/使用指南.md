# 用 AI 下载和新建语雀文档（li-yuque-skills）

## 这是什么

**li-yuque-skills** 是一个 AI skill（技能包）。装上之后，你可以直接对 AI 说话，让它：

- **下载**：把语雀上的知识库、某个目录或某一篇文档，下载成电脑上的 Markdown 文件，图片一起保存；
- **新建**：把电脑上写好的文档（或让 AI 帮你写的内容）发到语雀上。

它只会下载和新建，**不会修改、也不会删除**语雀上已有的文档。

- 支持的 AI 工具：**Claude Code、Codex、Cursor**，任选一个
- skill 名称：`li-yuque-skills`
- GitHub 仓库：{{REPO_URL}}

## 使用前提

- 电脑上装好了上面任意一个 AI 工具。
- 你的语雀账号能打开要下载的知识库。
- 要新建文档，你的账号需要对目标知识库有编辑权限，比如「{{BOOK_NAME}}」。

## 第一步：安装（只需一次）

打开你的 AI 工具，**按你用的工具**复制下面对应的一句话发给它：

| 你用的工具 | 对 AI 说 |
|---|---|
| Claude Code | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a claude-code -y`，把 li-yuque-skills 安装到全局 |
| Codex | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a codex -y`，把 li-yuque-skills 安装到全局 |
| Cursor | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a cursor -y`，把 li-yuque-skills 安装到全局 |

装好后，**新开一个对话**。

- `-g` 表示装在全局：以后在任何项目、任何文件夹里都能用，不用每个项目各装一次。
- 如果 AI 说电脑上没有 Node.js、问你要不要安装，回答"同意"即可。只需要装一次。
- **GitHub 打不开？** 下载本文附件 [li-yuque-skills-installer.js]({{INSTALLER}})，然后对 AI 说：「运行『下载』文件夹里的 li-yuque-skills-installer.js，把 li-yuque-skills 安装到全局」。

## 第二步：登录语雀（只需一次，过期了再做）

AI 需要你的语雀登录凭证（cookie）才能访问你能看到的文档。

1. 用 **Chrome** 或 **Edge** 打开 [www.yuque.com](https://www.yuque.com) 并登录。
2. 按键盘上的 **F12**，打开开发者工具。
3. 点顶部的「**应用**」（英文界面叫 **Application**）。找不到的话，点 `>>` 展开更多。
4. 左侧找到「**Cookie**」，点开，选 `https://www.yuque.com`。
5. 在右侧列表里找到名称为 **`_yuque_session`** 的那一行，双击它的「**值**」一栏，按 **Ctrl+A** 全选、**Ctrl+C** 复制（Mac 用 Cmd）。
6. 回到 AI 对话，说：

   > 语雀登录，cookie 已复制。

AI 会从剪贴板读取并保存，成功后显示你的语雀昵称。之后每次使用都不用再登录，直到语雀登录过期。

**安全须知**

- cookie 等同于你的语雀账号，**不要发给任何人，也不要直接粘贴到 AI 对话框里**，只在剪贴板里交给 AI。
- 登录成功后，随便复制一段别的文字，把剪贴板里的 cookie 覆盖掉。
- cookie 保存在你电脑上的 `用户目录/.li-yuque-skills/` 文件夹里，只有这台电脑上的 AI 会用到。

## 第三步：允许往知识库新建（只需一次）

为了防止 AI 把文档发错地方，新建只能发到你允许过的知识库。对 AI 说：

> 把 {{BOOK_URL}} 加入语雀新建白名单。

以后要往别的知识库新建，也是这样先说一次。下载不受这个限制。

## 第四步：开始用

用平常的话告诉 AI 就行，下面是一些例子。

**下载**

> 把 https://www.yuque.com/xxx/yyy 这个知识库下载到桌面。

> 下载这个知识库里「产品资料/报价」这个目录：https://www.yuque.com/xxx/yyy

> 把这篇文档下载下来：https://www.yuque.com/xxx/yyy/zzz

**新建**

> 把 D:\文档\周报.md 发到语雀「{{BOOK_NAME}}」知识库。

> 帮我把刚才的会议内容整理成纪要，发到语雀「{{BOOK_NAME}}」的「会议记录」目录下。

新建前，AI 会先给你看预览：发到哪个知识库、哪个目录、标题是什么。**你回复"确认"后，它才会真正发布。**

## 常见问题

**提示"登录已失效"怎么办？**
重新做一遍第二步。

**下载的文件在哪？**
没指定的话，在 AI 当前工作的文件夹里，以知识库名命名。也可以直接告诉 AI 存到哪里，比如"下载到桌面"。

**有些文档没下载下来？**
表格、数据表等类型暂时不支持，AI 会在最后列出跳过了哪些。思维导图会转成层级列表。

**想修改已经发布的文档？**
本工具不能修改，请到语雀网页上改。

**文档里的图片和附件会一起上传吗？**
会，文档里引用的本地图片和附件会自动上传。但语雀免费账号不能上传压缩包（zip、rar、7z）。

**怎么更新到新版本？**
把第一步那句话再对 AI 说一遍即可，不用重新登录，白名单也会保留。
