## 1. 安装（只需一次）

按你用的工具，把对应的一句话发给 AI：

| 工具 | 对 AI 说 |
|---|---|
| Claude Code | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a claude-code -y` 安装 li-yuque-skills |
| Codex | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a codex -y` 安装 li-yuque-skills |
| Cursor | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a cursor -y` 安装 li-yuque-skills |

也可以直接说：「从 GitHub 仓库 {{OWNER}}/li-yuque-skills 把 li-yuque-skills 安装到全局」。

装好后**新开一个对话**。装在全局，所有项目都能用。电脑上没有 Node.js 时，AI 会问你要不要安装，同意即可。

## 2. 登录（只需一次，过期了再做）

1. 用 Chrome 或 Edge 打开 [www.yuque.com](https://www.yuque.com) 并登录（公司空间的同事也在这里登录）。
2. 按 **F12** →「**应用**」（Application）→ 左侧「**Cookie**」→ `https://www.yuque.com`。
3. 找到 **`_yuque_session`**，双击「值」，全选复制。
4. 对 AI 说：「语雀登录，cookie 已复制」。

cookie 等同于你的语雀账号：**不要粘贴到对话里，也不要发给任何人**。AI 会从剪贴板读取，登录成功后随便复制点别的覆盖掉即可。

## 3. 怎么用

直接对 AI 说：

| 想做的事 | 这样说 |
|---|---|
| 不知道怎么用 | 语雀 skill 怎么用 |
| **发链接直接读** | https://www.yuque.com/xxx/yyy/zzz 这篇讲了什么？ |
| 搜索 | 在「{{BOOK_NAME}}」里找一下标题带「Skills」的文档 |
| 下载 | 把「{{BOOK_NAME}}」的「AI开发协作」目录下载到桌面 |
| 新建 | 把 D:\文档\周报.md 发到语雀「{{BOOK_NAME}}」的「某目录」下 |
| 列出知识库 | 列出我能访问的语雀知识库 |
| 更新 skill | 更新语雀 skill |
| 更新 cookie | 更新语雀 cookie，已复制 |

- **发链接直接读**：一次可以发多个链接，AI 读完直接回答，不保存文件。
- **搜索**：按目录和标题模糊匹配，多个关键词用空格分开；说明在哪个知识库会快很多。
- **新建**：AI 会先给你看预览（知识库、目录、标题），你确认后才发布。

## 常见问题

**会不会被封号？**
语雀没有公开网页接口的频率上限，但服务协议写明会处理异常行为。本工具按约 1 秒 1 次访问，遇到限流自动等待，日常使用风险很低。请不要短时间反复下载整个知识库，也不要让 AI 循环或同时开多个任务；提示"访问过于频繁"时，过 1 小时再试。

**有什么做不到？**
不能修改、删除已有文档（请到网页上操作）；表格、数据表暂不支持读取和下载；免费账号不能上传压缩包。

**skill 有新版本了怎么办？**
AI 会提醒你，说「更新语雀 skill」即可，不用重新登录。
