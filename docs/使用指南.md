# li-yuque-skills

> 让 AI（Claude Code、Codex、Cursor）直接读取、搜索、下载语雀文档，新建、修改文档，删除自己创建的文档。

## 1. 安装（只需一次）

按你用的工具，把对应的一句话发给 AI：

| 工具 | 对 AI 说 |
|---|---|
| Claude Code | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a claude-code -y` 安装 li-yuque-skills，装好后带我上手 |
| Codex | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a codex -y` 安装 li-yuque-skills，装好后带我上手 |
| Cursor | 运行 `npx skills add {{OWNER}}/li-yuque-skills -g -a cursor -y` 安装 li-yuque-skills，装好后带我上手 |

也可以直接说：「从 GitHub 仓库 {{OWNER}}/li-yuque-skills 把 li-yuque-skills 安装到全局，装好后带我上手」。

装好后 AI 会运行引导，一步步带你登录、试用；如果没有，新开一个对话说「语雀 skill 怎么用」。装在全局，所有项目都能用；电脑上没有 Node.js 时，AI 会问你要不要安装，同意即可。之后**每天第一次使用时会自动更新**，并告诉你更新了什么。

## 2. 登录（只需一次，过期了再做）

1. 用 Chrome 或 Edge 打开 [www.yuque.com](https://www.yuque.com) 并登录（公司空间的同事也在这里登录）。
2. 按 **F12** →「**应用**」（Application）→ 左侧「**Cookie**」→ `https://www.yuque.com`。
3. 找到 **`_yuque_session`**，双击「值」，全选复制。
4. 对 AI 说：「语雀登录，cookie 已复制」。

cookie 等同于你的语雀账号：**不要粘贴到对话里，也不要发给任何人**。AI 会从剪贴板读取，登录成功后随便复制点别的覆盖掉即可。

## 3. 怎么用

直接对 AI 说：

| 想做的事 | 这样说 |
|---|---|
| 不知道怎么用 | 语雀 skill 怎么用 |
| **发链接直接读** | https://www.yuque.com/xxx/yyy/zzz 这篇讲了什么？ |
| 搜索 | 在「{{BOOK_NAME}}」里找一下标题带「Skills」的文档 |
| 下载 | 把「{{BOOK_NAME}}」的「AI开发协作」目录下载到桌面 |
| 新建 | 把 D:\文档\周报.md 发到语雀「{{BOOK_NAME}}」的「某目录」下 |
| 修改 | 把这篇里的「旧说法」改成「新说法」：<文档链接> |
| 删除 | 删除我建的这篇：<文档链接> |
| 列出知识库 | 列出我能访问的语雀知识库 |
| 更新 skill | 更新语雀 skill（平时每天自动更新，一般不用说） |
| 更新 cookie | 更新语雀 cookie，已复制 |

- **发链接直接读**：文档、表格都能读，一次可以发多个链接，AI 读完直接回答。文档里的图片和附件（如 HTML 原型、PDF）会下载到电脑的临时目录，AI 也能打开看；图片多的文档第一次读要等一会儿。
- **下载**：表格转成 Markdown 表格，图片存到 `img/`，附件存到 `files/`。单个附件超过 50 MB 默认不下载，需要时对 AI 说「附件也下载，上限调到 500 MB」。
- **搜索**：按目录和标题模糊匹配，多个关键词用空格分开；说明在哪个知识库会快很多。
- **新建、修改、删除**：AI 都会先给你看预览，你确认后才执行。
- **修改**：你在语雀上有编辑权限的文档都能改（自己的、同事的都行）。AI 会先读最新内容再改，整篇替换；字体颜色、卡片等 Markdown 表达不了的样式会丢失。改错了可以在文档的「历史版本」里恢复。
- **删除**：只能删你自己创建、且下面没有子文档的文档。删除的文档进入知识库「回收站」，可以恢复。

## 常见问题

**会不会被封号？**
语雀没有公开网页接口的频率上限，但服务协议写明会处理异常行为。本工具按约 1 秒 1 次访问，遇到限流自动等待，日常使用风险很低。请不要短时间反复下载整个知识库，也不要让 AI 循环或同时开多个任务；提示"访问过于频繁"时，过 1 小时再试。

**cookie 多久要重新登录一次？**
语雀登录有效期 30 天，每次使用都会自动续期，正常使用不用管。超过 30 天没用、在浏览器里点了「退出登录」或改了密码时会失效，AI 会提示你重新登录（平时关掉网页即可，不用点退出）。

**有什么做不到？**
不能删除别人创建的文档或带子文档的文档（请到网页上操作）；数据表暂不支持读取和下载，正文里嵌入的数据表、视频也读不到；免费账号不能上传压缩包。

**skill 有新版本了怎么办？**
不用管。每天第一次使用时会自动更新，并告诉你更新了什么；新开对话后新功能生效。想马上更新就说「更新语雀 skill」。
